# Jo's Bakes & Sweet Treats Demo

A sales-focused demo website concept for Jo's Bakes & Sweet Treats, St Neots.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- Google Fonts
- Vercel-ready static deployment

## Demo notes

Product copy and imagery are placeholder/demo content until Jo's current catalogue, prices, product photography and ordering process are confirmed.

The enquiry form is intentionally a front-end demo and does not send or store customer data.
